04

Cross-cutting & risks

Cross-cutting workstreams

  • Time integrity — drift > 10 min already flagged server-side
  • Retention — 7-day ping purge verified; confirm daily cron
  • Observability — wire Supabase + function logs, monitor health
  • Accessibility & i18n pass (web + app)

Known risks

  1. Android not yet compiled — first build likely surfaces small API fixes
  2. Firebase placeholder — FCM inert until real credentials
  3. pg_cron / pg_net must be enabled for jobs + push
  4. OpenFreeMap tiles — check rate limits or self-host for prod
Suggested next step

Trigger CI so the Android assembleDebug runs for the first time. That single signal resolves the biggest open risk (Phase 2) and tells us exactly what — if anything — needs adjusting before on-device testing.
